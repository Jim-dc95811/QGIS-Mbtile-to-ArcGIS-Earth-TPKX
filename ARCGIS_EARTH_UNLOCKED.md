# ArcGIS Earth Unlocked

This repository is the **foundation-map production** branch of the broader ArcGIS Earth project family.

Master system map:

https://github.com/Jim-dc95811/ArcGIS-Earth-Unlocked

Current object-authoring center:

https://github.com/Jim-dc95811/ArcGIS-Earth-Object-Factory

Project role:

> **QGIS MBTiles → TPKX builds the durable offline world.**

Other major branches:
- **EarthStick** — joystick navigation
- **Object Factory** — beacons, sky objects, batch objects, links, and experiments
- **Point Maps / PointLayer** — public ArcGIS point-service ingestion
- **Parcel100** — clickable offline parcel intelligence
- **ArcGIS Earth Offline Maps & Chartplotting** — earlier offline-map/mobile/chartplotting/field-tracker workflows

The tools remain separate so each one keeps a clear job; ArcGIS Earth is the common environment that brings them together.
