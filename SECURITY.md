# Security and responsible reporting

Please do not post sensitive details, private agency records, confidential map locations or passwords in public issues. This local file-conversion project is not independently security-certified. Use synthetic sample data when reporting problems.

If this repository has GitHub private reporting enabled, use its Security tab. Otherwise, open a public issue with no sensitive information and ask for a private way to contact the maintainer.

The owner can [enable private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository). This file does not claim that it is enabled or that response times are guaranteed.
